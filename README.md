## 🎯 Project Goal

The goal of this project is to build an AI-powered retail assistant that helps customers with:
- 🔍 **Finding products**
- 💡 **Product recommendations**
- 🖨️ **Printer compatibility**
- 📦 **Order tracking**
- 🕒 **Previous orders**
- 🏪 **Store availability**
- 🎙️ **Voice support (planned)**

> **💡 The Inspiration:** This project was inspired by my experience working at **Argos**. I noticed that customers often ask the same questions repeatedly, and I wanted to build a solution that saves time for both customers and employees.

## 📂 Current Project Structure

The project is cleanly split into two main folders:
- 🎨 `frontend/`: Contains all the React UI code, components, and Tailwind styles.
- ⚙️ `backend/`: Contains the Express server, AI logic, custom tools, and our JSON retail database.

## 📖 Why I Built This

While working at Argos, I noticed customers often ask employees questions such as:
- *"Where is my order?"*
- *"Which ink fits my printer?"*
- *"Is this product available nearby?"*
- *"Can you recommend a similar product?"*

I wanted to build an AI assistant that can answer these questions instantly, providing a seamless shopping experience and allowing retail staff to focus on more complex tasks.
